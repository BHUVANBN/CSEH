## [CEH EXAM FOCUS]

### Common Exam Question Areas for Footprinting Methodology

1. **Scenario-based identification** — Given an attack description, identify the technique from: passive/active recon, OSINT sources, whois, shodan, netcraft, maltego, footprinting methodology, countermeasures
2. **Tool selection** — Which tool is appropriate for a given task?
3. **Protocol/process knowledge** — Step-by-step understanding of how mechanisms work
4. **Defense questions** — What control prevents or detects this attack?
5. **Legal/ethical context** — Is this activity authorized? What documentation is needed?

### Tricky Areas
- Exam questions often include distractors that are partially correct
- Know exact port numbers, protocol names, and tool syntax
- "Best" answers prioritize least invasive / most targeted approach
- Time-based questions: passive recon before active; scanning before exploitation
